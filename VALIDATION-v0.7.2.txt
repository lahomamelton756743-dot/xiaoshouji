Recommended deployment order
1. Back up / bind the existing production D1; do not create an empty replacement database.
2. Deploy the v0.7.2 Cloudflare Worker against the existing D1.
3. Verify bootstrap and historical data before any APK rollout.
4. Deploy/configure Mi Health Bridge separately (Python 3.11+, Xiaomi small-account token,
   friend-sharing authorization, optional Bridge secret).
5. Configure XIAOMI_HEALTH_BRIDGE_URL / XIAOMI_HEALTH_BRIDGE_TOKEN only if active refresh is wanted.
6. Build/sign Android with SDK 34, install v0.7.2 (versionCode 70320), then perform real-device QA.
