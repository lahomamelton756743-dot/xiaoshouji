# 小手机 v0.3.2

这一版根据第一次真机安装结果修正：

- 首页底栏统一为：首页｜留痕｜＋｜消息｜我们。
- 五个底栏入口都有实际行为，不再只有首页可点。
- `＋` 直接进入留痕编辑区。
- 「消息」新增独立页面，并新增 server/MCP 消息接口；每条消息保存 `created_at`。
- 「我们」回到原掌心窗已有的陪伴、日记、重要日期/纪念日能力。
- 留痕、留痕纸条都显示各自时间。
- 独立包名导致配置不共享：首次进入留痕/消息时会弹出“小手机连接”窗口，要求在本机填写 server URL、LINJIAN_TOKEN 和 device id。
- 修复空 server 时直接拼出 `/api/traces` 导致 `no protocol` 的错误。
- Android 请求同时发送 `X-Auth-Token` 与 Bearer Token；server 也兼容两种认证格式。
- 首页增加「最近消息 / 最近留痕」玻璃预览卡。
- 截图入口继续关闭；辅助服务仅保留其他已授权的设备操作。

注意：留痕和消息是服务端数据，因此仅重新构建 APK 不够。部署端的 `server/` 和 `mcp/` 也需要运行这一版代码，新的 `/api/messages` 和 MCP 消息工具才会生效。
