# 小手机 v0.3

- 独立应用 ID：`com.littlephone.app`，显示名称「小手机」，可与原掌心窗并存。
- 默认全局主题改为「液态玻璃」：暖白、雾蓝、浅灰紫，低饱和粉仅作关系点缀；卡片、底栏、浮层统一半透明玻璃语言。
- 首页主组件改为「现在」：大号本地时间 + 日期/星期 + 当前天气/地区摘要，并继续复用掌心窗现有天气和日历/重要日期数据。
- 留痕沿用 v0.2：文字、最多 9 张图片、纸条回复；每条留痕保留创建时间。
- 纸条/回复继续使用独立 `created_at`，用于逐条显示时间。
- 导航目标：`首页｜留痕｜＋｜消息｜我们`。
- 截图能力关闭：Android 截图入口变为 no-op，MCP 不再注册 `peek_screen` / `latest_screen`。无障碍服务仍保留其他既有设备动作。
- 原掌心窗日历与重要日期作为「我们/纪念日」的数据来源，不重复造一套。

后续：消息页、状态、小纸条首页贴附、时间胶囊与更强的 Android 12+ 模糊/折射效果继续在独立小手机包中迭代。
