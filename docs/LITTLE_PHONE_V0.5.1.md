# 小手机 v0.5.1｜视觉回归与结构整理

基线：v0.5 功能结构 + v0.4.1 视觉母版。

## 视觉

- 恢复 v0.4.1 的冰蓝、珍珠白、浅灰紫与极淡粉紫折射。
- 恢复轻薄玻璃、高光、内部彩色光晕、时间主卡光球。
- 恢复软玻璃底栏与液态水滴 `＋`。
- 卡片按主卡/普通卡/内容卡/弹窗/底栏分层，不再统一成厚白卡。

## 首页

- daddy 头像在左、瑞安头像在右，中间透明软线；来访时流光。
- 两个头像都可点击更换，头像图保存在 WebView 本地存储。
- 保留时间天气主卡、最近一封信、随机纸条、最近留痕、今天/待办/下一件重要日期。
- 不再把电量、网络、权限单独做首页大卡。

## 纸条箱

- 纸条从信箱移出，首页随机纸条点开进入独立纸条箱。
- 纸条箱可查看历史、写纸条、手动换首页纸条。
- 约 10 分钟自动换一张；离开 App 超过 10 分钟回来会换一张。
- 使用洗牌袋逻辑，一轮内尽量不重复。
- MCP `leave_little_phone_paper` 继续允许 daddy 写纸条。

## 留痕 + 日常册

- 留痕继续是 7 天独立过期的事件时间轴：瑞安在左，daddy 在右；按天折叠。
- 新增手动 `留一条痕迹` 接口与 MCP 工具 `leave_little_phone_trace`。
- 日常册移到留痕页下半部分。
- 日常册改为横向可滑动的弯曲“时间河”，日期点落在河线上，玻璃气泡挂在上下两侧；点气泡展开全文与照片。

## 信箱

- 信箱只放信。
- 普通信与未来信/时间胶囊分区显示。
- 首次拆普通信会写入一条“小手机留痕”。
- 打开已解锁未来信会在本机防重复后写入留痕。

## 我们

- 顶部保留双头像、第 N 天和简短状态，不显示“daddy 在左 / 瑞安在右”说明文字。
- 页面优先展示纪念日、时间胶囊、来访记录、设备权限、连接设置。
- 来访权限开关藏到二级弹窗，不再一打开“我们”就满屏设置。
- “系统权限”入口直接打开当前小手机 App 的系统详情页，不再跳回旧掌心窗主页。

## 待办

- 首页最多露出 3 条未完成事项。
- 完整待办通过弹窗查看。
- 服务端新增待办更新接口，支持修改标题、到期时间、提醒时间。
- MCP 新增 `update_little_phone_todo`。
