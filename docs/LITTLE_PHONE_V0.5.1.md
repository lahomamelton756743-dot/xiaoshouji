# 小手机 v0.5.1｜当前锁定稿

视觉：继承 v0.4.1。冰蓝、珍珠白、浅灰紫、极淡粉紫折射；薄玻璃、柔光团、软玻璃底栏、水滴 `＋`。功能继续使用 v0.5 架构。

## 一级页面

### 首页

- 双头像与名字均可编辑并同步显示。
- 两个头像距离更近，中间是轻微不规则弯曲的耳机线；右侧为小状态区。
- 时间天气主卡。
- 手机状态/使用情况摘要：电量、网络、屏幕时间、解锁次数。
- 随机纸条、最近 3–4 条留痕、今天待办/下一件重要日期。

### 留痕

- 小手机事件每条独立保留 7 天。
- 顶部采用固定高度滑动区，不无限撑开。
- 日常册位于下半部分：横向蜿蜒“时间河”，左右滑动，日期点沿河分布，玻璃气泡挂在上下两侧。
- 日常册支持照片、修改记录所需字段与删除。

### 信箱

- 只放普通信与未来信/时间胶囊信。
- 纸条不属于信箱。
- 可删除。

### 我们

- 关系主页优先，不做设置页。
- 第 N 天点击进入重要日期月历；天数从 `relationship_start` 读取。
- 纪念日、周期记录、时间胶囊、来访记录、主动提醒、设备权限、应用门禁、连接设置均为二级入口。

## 数据/设备原则

- 用户可创建的长期内容均提供删除能力。
- 一次 daddy 来访只采集一次授权设备快照，默认 30 分钟过期。
- 设备权限 UI 会打开真实 Android 权限/设置入口；访问策略与系统权限是两层控制。
- 首页天气使用 Android 位置权限，可显式刷新。
- 断网时保留最近一次成功同步到本地 SQLite 的内容，不把失败显示成“空数据”。
- 主动提醒和应用门禁在设备本地执行；服务端 generic command 只允许提醒/门禁白名单动作，不开放旧的通用点按控制。
- 截图能力关闭：旧截图 API 返回 410，Android 不上传截图，MCP 不暴露截图工具。
