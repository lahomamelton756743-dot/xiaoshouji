# 留痕 v0.2 Android

- 新增 `TraceActivity` 独立留痕页。
- 主界面原“陪伴”底栏入口暂改为“留痕”，点击进入新页。
- 留痕页支持：刷新、文字发布、系统相册多选（最多 9 张）、图片上传/浏览、纸条查看与回复。
- 底部加入第一版悬浮玻璃导航视觉草案：首页 / 留痕 / ＋ / 消息 / 我们。
- 数据继续使用 v0.1 的 `/api/traces` 和 MCP 留痕工具，不依赖无障碍。

注意：当前运行环境没有 Android SDK 34，因此这里无法本地生成 APK；源码改动已完成，但需要 GitHub Actions 或装有 Android SDK 34 的构建环境做 APK 编译验收。
