# v0.5.1 R3 hotfix

针对真机反馈的三项修复：

1. 头像：不再依赖 WebView `<input type=file>`。Android 原生直接打开系统相册/文件选择器，中心裁切并压缩为 320×320 JPEG 后保存在本机；首页/“我们”页同步刷新。双头像从 54px 调整到 60px。
2. 留痕：新增本机待同步留痕队列。打开小手机、打开纸条箱、修改资料、手动刷新天气等本机行为即使 server 临时不可达，也会先出现在留痕中，标记“本机待同步”；恢复连接后自动同步。成功的信/纸条/待办等远端写入仍由后端记录，避免正常情况下重复记账。
3. server 连接：离线条会显示更具体的错误类别（Token 不匹配 / 域名解析失败 / 连接超时 / 网络无法连接），点击离线条可重新测试；连接设置会自动去掉误填的 `/mcp` 或 `/health` 后缀。

Android versionCode: 50103（versionName 仍为 0.5.1）。
