# 小手机 v0.5.1 R4 修复说明

## 这轮针对的实际问题

1. 纸条箱里再打开写纸条时，编辑弹窗被旧弹窗压住。
2. 纸条、信、纪念日、周期记录偶发 `timeout`。
3. 归电头像和小手机资料头像不一致，归电参数不够完整。
4. Android 返回手势直接退出 App；只能点 × 关闭弹窗。
5. “我们”页需要独立的 daddy/GPT 日记。

## R4 处理

- 动态 modal stack，后打开的编辑弹窗始终处于最上层。
- 点击弹窗外遮罩即可关闭。
- Android 返回手势优先关闭顶层弹窗，再返回上一页，首页才退出。
- 原生 HTTP 连接与读取超时和 JS 等待窗口重新匹配，错误会及时回传。
- 首页同步改为单次 `/api/littlephone/bootstrap` 请求，减少移动网络并发请求。
- 纸条、信、纪念日、周期记录支持本地先保存；server 恢复后自动同步。客户端 ID 保证创建重试幂等。
- 周期设置先写入 Android 本机，再尝试同步 server。
- 归电头像优先读取“小手机 → 我们”里设置的 daddy 头像。
- 归电设置加入离开时长、冷却、每日最多次数、安静时段、全屏来电式弹窗等。
- 新增 daddy/GPT 日记：独立封面、一篇一页、上一页/下一页、正文纵向滚动与进度条。
- 后端新增 `lp_diaries`、日记 API/MCP 工具与 bootstrap 聚合接口。

## 后端

R4 修改了 Cloudflare Worker，安装 R4 后必须重新运行现有的“小手机后端 v0.5.1（全新）”部署工作流。D1 名称仍为 `little-phone-v051`，不会新建第二套数据库；新表通过 Worker 的 `CREATE TABLE IF NOT EXISTS` 自动创建。
