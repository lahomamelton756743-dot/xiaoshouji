# 小手机 v0.5.2

本版重点不是继续堆卡片，而是重新组织首页、留痕、我们、来电、日记与健康数据之间的关系。

- 首页：时间 → 待办 → 手机状态 → 双方足迹。
- 留痕：纸条 + daddy 来电记录 → 横向日常册时间河。
- 我们：双头像轻碰动画 + 双方状态 + 纪念日 + 书式 daddy 日记 + 小米健康。
- 来电：原归电改名来电；支持自定义来电、目标包名、拒绝留言、延迟重拨和通话记录。
- 健康：只固定数据契约；真实 Xiaomi / mi-fitness-python bridge 最后接入。
- MCP：本版只更新 Worker 的工具契约，不创建最终 ChatGPT 插件。
