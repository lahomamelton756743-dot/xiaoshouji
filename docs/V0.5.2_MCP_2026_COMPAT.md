# v0.5.2 MCP 2026 compatibility fix

This release keeps the existing Android, Netlify gateway, D1 schema, API surface, and OAuth flow, and upgrades only the Cloudflare Worker MCP transport compatibility.

## Changes

- Adds MCP 2026-07-28 `server/discover` support.
- Keeps legacy MCP `initialize` compatibility using 2025-11-25, plus compatibility with 2025-06-18 clients.
- Advertises the full tool surface before account linking.
- Mirrors each tool's OAuth `securitySchemes` into `_meta.securitySchemes` for ChatGPT compatibility.
- Adds MCP tool annotations for read-only / destructive / closed-world behavior.
- Adds modern server identity metadata to MCP results.
- Keeps actual `tools/call` protected by OAuth or the existing LINJIAN_TOKEN compatibility path.
- Accepts both ChatGPT OAuth callback URL forms used by the current connector flow.
- Adds RFC 9207 `iss` to authorization responses.

## Deployment

Deploy the existing `little-phone-backend` Worker against the existing `little-phone-v051` D1 database. No APK reinstall and no Netlify changes are required.
