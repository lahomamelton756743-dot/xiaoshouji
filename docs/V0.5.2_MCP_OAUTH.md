# 小手机 v0.5.2 · ChatGPT MCP OAuth

本补丁只为现有 Cloudflare Worker 增加标准 OAuth 2.1 授权，不改变 Android 小手机的 Netlify API 入口。

## 保留的认证

- Android App / 旧客户端仍可使用原 `LINJIAN_TOKEN`。
- `/mcp` 新增 OAuth 2.1 Authorization Code + PKCE（S256）。
- OAuth access token 有效 1 小时；refresh token 有效 90 天并在刷新时轮换。
- 授权页使用现有 `LINJIAN_TOKEN` 作为一次性“连接口令”验证，口令不会写入 OAuth token 表。

## 自动发现端点

- `/.well-known/oauth-protected-resource/mcp`
- `/.well-known/oauth-authorization-server`
- `/register`（Dynamic Client Registration）
- `/authorize`
- `/token`
