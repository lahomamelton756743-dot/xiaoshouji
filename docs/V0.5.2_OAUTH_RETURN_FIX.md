# v0.5.2 OAuth return fix

- Keep the standard 302 response when `/authorize` is called directly on the Worker.
- When Netlify proxies `/authorize`, return a no-store browser handoff page that uses JavaScript, meta refresh, and a manual link to return to ChatGPT. This avoids a successful Worker 302 being swallowed by the Netlify rewrite.
- Trim copied connection token before comparison.
- Keep no-cache headers on every successful authorization response.
- No Android, frontend, Netlify or D1 changes.
