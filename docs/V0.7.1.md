# 小手机 v0.7.1

- 一级导航改为：日记 / 留痕 / 首页 / 信箱 / 状态；首页仍为中间放大的主入口。
- 日记独立成一级单页，默认直接展示封面。
- 首页顶部改为渐变花体相伴天数；时间卡保留团雀月亮，天气位置显示 daddy 天气留言。
- 双头像与一起听移到首页：头像靠左相碰，耳机线从耳朵位置引出、缠绕并自然垂落；音乐胶囊右侧使用爱心波形。
- 首页直接展示完整仿真实体月历，重要日子用身份色标记；日历下方为待办。
- 状态页顺序：小米健康 / 足迹 / 手机状态；来电提醒、权限、门禁、连接和背景全部收进右上角设置入口。
- 支持全局背景和每页独立背景；卡片透明度调整为更清透的液态玻璃。
- 普通信与未来信继续分区；轮播首尾循环；已拆/未拆信封区别加强，信头使用寄件人/日期格式。
- “{display_name} 记得”补齐 confirm/correct MCP 工具。
- 版本升级为 0.7.1 / backend 0.7.1-little-phone。
