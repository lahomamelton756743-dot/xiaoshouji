# 小手机 v0.7.2

这是针对 v0.7.1 真机联调的修复版。

- 修复底栏首页已选中但日记液态气泡仍停在第一格的问题；选中态现在直接绑定 active tab。
- 首页双头像去掉僵硬耳机线，改成头像之间的细线 + 中央空心爱心。
- 正在播放区域取消独立玻璃框，歌名/歌手直接显示，右侧保留爱心波形。
- 远端数据读取不再依赖单个 `/api/littlephone/bootstrap` 成败；纸条、信箱、来电、待办、日记、日常册、状态等分别读取，单个接口失败不会清空其他模块。
- Android HTTP bridge 增加 `LittlePhoneHTTP` Logcat 日志，记录实际 URL、HTTP 状态码、响应长度和截断后的响应前缀，便于真机排查。
- 不重建、不清空 D1。
