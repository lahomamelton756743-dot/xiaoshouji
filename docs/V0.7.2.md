# little-phone v0.7.2 实施记录

基线：从稳定 v0.6.3 重建出的 v0.7.1 稳定线继续升级。没有把失败历史 0.7.x 的数据读取方案重新引入。

## 本轮重点

- 信箱：真实封口纸信封、火漆封缄、拆后仿真长信纸、正式书信格式。
- 身份字体：Android 本地白名单、Cloudflare profile 白名单和 WebView 渲染统一支持 clean / rounded / cheese / serif / kai / italic / script / mono。
- 一起听：纵向音柱构成心形波形，歌曲与歌手层级分开。
- 首页：Together 更轻更横向；天气卡略收短；团雀月亮更饱满；天气留言走 daddy 身份字体。
- 月历：首页点日期进入简化标记流程，取消常驻 legend。
- 背景：每页单独保存压缩背景，修复大 JSON 导致的“选了但不生效”风险；玻璃透明度降低。
- 留痕：纸条正文主导，回复框和操作按钮降权。
- 记得：新增 list/create/update/confirm/correct/delete 六个直接 MCP 工具别名，全部复用 lp_memories 并保持更新原 ID。
- 小米健康：新增独立 Python Bridge、按日期 D1 摘要、MCP 睡眠/心率/步数工具与可选主动刷新链路。
