# little-phone v0.7.3 实施记录

基线：v0.7.2；继续继承稳定 v0.6.3 数据链。

## 视觉与交互

### Together / 一起听

- 删除双头像之间的连接线。
- 双头像并排集中在组件左侧，进入首页时执行一次柔和相碰动画。
- 音乐信息移到右侧，分别显示歌名、歌手、来源和播放状态。
- 下方独占一行长心形音柱：心形核心动画幅度小、左右音柱幅度大；播放时有横向流光，暂停时静止。
- Android 当前只提供播放状态而非真实音频幅值，因此不伪造逐拍音频分析。

### 日记

- 删除原底部上一页/下一页按钮。
- 轻触书页左半边向前翻、右半边向后翻。
- 纸张使用横线、页边、纸张阴影和页码；正文按日记纸版式排版。
- 翻页使用 3D page ghost 动画；编辑/删除按钮不触发翻页。

### 未来信

- 未到日期或到期但尚未拆：显示完整信封、三角封口和蜡封。
- 已拆：显示信封和抽出的信纸，不与普通信复用同一视觉。

### 首页 / 玻璃

- 顶部新增花体叠字、细曲线和光点，允许轻微覆盖天气卡。
- 装饰层 `pointer-events:none`，不能挡住卡片交互。
- 全局玻璃降低白底不透明度，提高 blur、边缘高光和背景透出。

## 设置页 bug

问题根因之一：设置列表已经绑定 `openSettingsSection(...)`，但旧前端没有实现该函数，点击后抛出 ReferenceError；动态创建的部分详情按钮也缺少事件绑定。

v0.7.3：

- 实现 `openSettingsSection()` 并进入 `settings-detail`。
- `renderSettingsDetail()` 每次创建 DOM 后重新绑定事件。
- 修复来电/提醒测试、设备权限、天气刷新、门禁权限/刷新/添加锁定、连接配置和外观入口。
- 保留现有设置功能，不删除设置页面。
- 加强 settings 页 z-index / pointer-events，避免透明装饰层拦截点击。

## 小米健康 APP 联调

- 状态页进入时自动调用 `POST /api/littlephone/health/refresh`，日期使用本地 `YYYY-MM-DD`。
- 成功后直接更新 `state.health` 与本地缓存。
- 健康弹窗保留手动“刷新最新数据”。
- Render 冷启动期间显示“正在读取/唤醒健康服务”，不是直接显示未连接。
- Android `LittlePhoneActivity` 对 `/api/littlephone/health/*` 使用 12s connect / 75s read timeout；普通请求仍为 7s / 10s。
- 深睡、浅睡、REM 为 0/缺失时显示“暂无细分”。
