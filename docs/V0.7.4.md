# little-phone v0.7.4 实施记录

基线：v0.7.3；数据链继续继承稳定 v0.6.3 / v0.7.x 的 Cloudflare + D1 架构。

## 视觉基准

本轮按最终确认的四张设计图收敛，不再继续换风格：

- 首页：花体 Together、右侧 Days · With You、天气月亮团雀卡、双头像小爱心、长心形动态波形、玻璃月历。
- 日记：浅色真实纸张/装订本、左/右半页点按翻页、纸张纹理与页脚装饰，不保留底部翻页按钮。
- 信箱 / 未来信：普通信保持信纸质感；未拆未来信使用封口信封 + 蜡封 + 花枝；已拆显示抽出信纸。
- 状态：小米健康改成四指标摘要卡，足迹、手机状态与在线状态统一为柔和玻璃卡。

整体只加强透明度、blur、边缘高光和装饰层，不重新改变原有主色体系；亮度比设计稿略压低，避免真机过曝。

## Together / 一起听

- Together 使用真正 script/cursive 视觉和心形收尾。
- 左侧双头像每次进入首页轻轻靠近一次，头像之间使用小爱心，不再出现贯穿连接线。
- 右侧显示“一起听 / 歌名 / 歌手 / QQ音乐状态”。
- 底部波形改成 58 根纵向音柱，中间音柱构成清晰心形，两侧振幅更明显。
- 取消整片横向流光；播放时仅做柔和循环波动，暂停/无媒体时降为静态。
- 不伪造真实逐拍音频振幅。

## 日记

- 封面改成浅色实体日记本，不再使用深色大色块。
- 正文页保留纸张横线、纸边、书脊、页码、花枝和轻微翻页层次。
- 轻触左半边向前、右半边向后；编辑/删除按钮不触发翻页。
- 移除页面底部上一页/下一页控制与重复翻页提示。

## 信箱 / 未来信

- 普通信使用偏白/淡紫的纸张和邮寄视觉，不再使用厚重米黄色块。
- 未拆未来信：三角封口、蜡封、花枝、邮票/日期信息。
- 已拆未来信：纸张抽出，和未拆状态明显不同。

## 状态

- 小米健康顶部卡直接显示：睡眠时长、睡眠评分、今日步数、最近心率。
- 继续支持自动刷新与手动刷新；冷启动时不误判为未连接。
- 瑞安 / GPT 足迹维持双列；手机状态保持电量、网络、屏幕时间、解锁次数和 App 使用前五名。

## 设置与背景

- 设置页原有来电与提醒、设备权限、应用门禁、连接设置、外观与背景全部保留。
- 动态设置详情继续使用事件重新绑定，避免“页面能进但按钮没反应”。
- Android 新增 `pickBackground(page)` 原生相册入口；背景图片压缩后通过事件回传 WebView，并仅保存在本机。
- 支持全局 / 日记 / 留痕 / 首页 / 信箱 / 状态独立背景。
- 增加“恢复全部默认背景”。

## 小米健康

- APP 进入状态页继续调用 `POST /api/littlephone/health/refresh`。
- 深睡/浅睡/REM 缺失时显示“暂无细分”，不显示假 0。
- Android 对 `/api/littlephone/health/*` 继续使用较长读取超时，兼容 Render 冷启动。
