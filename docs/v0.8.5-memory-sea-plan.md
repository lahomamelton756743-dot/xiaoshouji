# 小手机 0.8.5 — 记忆星海（开发基线）

状态：开发分支，未发布，未接入生产 MCP，未生成 APK。

## 目标
1. 不部署 Ombre Brain，复用 Cloudflare D1 原始数据和现有 OAuth/MCP。
2. 新增只读 search_little_phone_memory：跨日记、记得、纸条、普通信、未来信、聊天、日常册、重要日期等已持久化数据，支持关键词、日期和来源过滤；返回来源、ID、日期、原文片段及可继续读取的标识。
3. Skill：每轮相关对话优先检索；不能承诺 ChatGPT 工具调度每轮必定调用；找不到不编造。
4. 星海模式：真实记录是星点，真实关联才连线；点开看原文；时间视图保留时间顺序。避免原来的粗线/塑料管效果。
5. 现有日记、信件、纸条、聊天、设置、健康功能均保持兼容。原始记录不因排序或“遗忘”而删除。

## 实现阶段
- A. 确认 D1 表结构和 MCP 注册位置，补统一只读检索及边界测试。
- B. 设计可复算的记忆片段和关联（先关键词/时间，后语义）；不得虚构人物事件。
- C. 安卓前端增加星海/时间双模式；验证小屏点击、性能和空状态。
- D. 写 Skill、做真实端到端测试、再构建 0.8.5 APK。

## 安全边界
仅在独立 feature/v0.8.5-memory-sea 分支工作；未经确认不合并 main、不部署 Worker、不迁移或删除数据。
