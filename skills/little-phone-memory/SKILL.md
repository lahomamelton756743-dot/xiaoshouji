# 小手机长期记忆检索 Skill（0.8.5 草案）

## 使用目的
在与用户正常聊天时，优先通过小手机 MCP 找回相关的真实记录；不要求用户说“搜索记忆”。本 Skill 不保证宿主每轮必定调度工具。

## 检索时机
- 用户提到过去的人、日期、承诺、日记、纸条、信件、聊天、事件、习惯或“你还记得”时，先搜索再回答。
- 日常闲聊中涉及可验证的共同经历时，优先查询相关记录。
- 不相关的纯常识、数学或创作任务无需无意义地调用记忆库。

## 工具优先级
1. 若已安装并开放 `search_little_phone_memory`，先使用统一搜索；关键词不足时扩大时间范围或改用相关词。
2. 若统一搜索尚未上线，则使用现有的读取工具：`get_gpt_memories`、`list_daddy_diaries`、`list_little_phone_papers`、`list_little_phone_mail`、`list_chat_messages`、`list_dailybook_entries`、`list_future_letters`、`list_important_dates`。仅使用当前连接实际可用的工具。
3. 需要准确细节时继续读取原文，不凭摘要补全。

## 真实性与边界
- 记录的作者、时间、来源及 ID 必须保持准确；不得编造或把推断当事实。
- 找不到时直接说明“没有找到相关记录”，不要声称自己记得。
- 检索只读；不得因检索修改、删除、标记已读或发送内容。
- 用户同意小手机中的相关记录可供聊天检索；访问仍受实际 MCP 认证和权限约束。
- 原始数据留在既有数据库，检索索引和星海不能替代原始记录。
- 工具故障不妨碍继续聊天，但要说明本次无法核实记忆。

## 星海
每颗星绑定真实来源 ID；点击显示原始记录；连接线需要可解释的关联依据。保留按时间排序的浏览方式，不自动遗忘或删除记录。
